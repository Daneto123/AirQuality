В папката на проекта се отваря конзола Command Prompt и там въвеждаме следната командта: docker compose up --build
Това стартира базата от данни influxDB. Когато искаме да спрем приложението използваме командата: docker compose down
Тествано е с Docker Desktop под Windows и с Windows Subsystem for Linux (Ubuntu 20.04)

За стартиране на influxDBApi трябва да се влезе в папката и отново да се отвори Command Prompt след което следната команда: node index.js
Всички необходими библиотеки са предваритрелно изтеглени. Конфигурирано е да използва порт 3060

За стартиране на processDataApi трябва да се влезе в папката и отново да се отвори Command Prompt след което следната команда: python app.py
Всички необходими библиотеки са предваритрелно изтеглени. Конфигурирано е да използва порт 5000
